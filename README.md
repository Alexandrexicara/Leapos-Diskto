# LeapOS

Sistema operacional Linux personalizado, com interface em português do Brasil e experiência visual inspirada em desktops modernos.

## Estado do projeto

Este repositório contém o código-fonte do sistema Linux e sua infraestrutura de construção de imagem ISO. O portal comercial é um projeto separado.

A primeira etapa é preparar uma imagem Live para testes em máquina virtual ou pendrive. Ainda não há instalador próprio para instalação no disco interno.

## Princípios

- Interface em português do Brasil.
- Operações de limpeza e gerenciamento com prévia e confirmação.
- Preservação dos arquivos pessoais e dos dados dos navegadores.
- Construção reproduzível da ISO por GitHub Actions.

## Segurança

Não execute operações destrutivas sem confirmação. Não remova arquivos pessoais, credenciais, histórico ou componentes essenciais do sistema.
